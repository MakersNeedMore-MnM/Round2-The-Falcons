# Phase 22: response simulation builder

## Delivered

- Console simulation builder at `/app/simulate`.
- Operator-selected risk analysis, incident, asset targets, response action, rationale, and rollback plan.
- Generated scenarios pass through existing policy evaluation and appear in the Decision Desk.

## Boundary

A simulation is decision support only. It does not alter live controls, execute a response, or bypass policy and multi-operator approval requirements.

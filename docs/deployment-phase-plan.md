# Cascadia deployment phase plan

## Completed product phases

1–37: platform foundation, PostgreSQL persistence, inventory/imports, live signed connectors, TAXII, ML review, incidents, identity, frontend, topology, notifications, evidence graph, data quality, governance, compliance readiness, connector catalog, PWA, resilience readiness, and executive brief.

## Deployment path

38. Production hardening and release gate.
39. Custom durable compliance frameworks (joint schema approval required).
40. Vendor activation: Entra, Resend, Slack/Teams, SIEM/EDR credentials.
41. Mobile operator companion and approved push delivery.
42. Release acceptance: accessibility, performance, security review, UAT, rollback drill.

## Recommended post-deployment expansions

43. CMDB/CSV/SBOM discovery adapters.
44. SCIM provisioning and Entra group-to-role mapping.
45. Retention schedules, legal holds, and evidence preservation.
46. Multi-region database recovery and restore validation.
47. External assessor evidence bundles and signed exports.
48. Dedicated vendor adapters with schema versioning and connector health SLAs.
